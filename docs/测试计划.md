# 测试计划

## 一、项目背景
本项目针对 SauceDemo 电商网站进行功能测试，验证登录、商品列表、购物车、结算四大核心模块的功能正确性、界面一致性及异常处理能力。

## 二、测试范围
1. 登录模块：标准用户登录、锁定用户拦截、密码错误、账号密码为空、账号不存在、密码掩码显示。
2. 商品列表模块：商品展示、价格排序、名称排序、商品详情跳转。
3. 购物车模块：添加商品、移除商品、购物车数量校验、进入购物车、继续购物。
4. 结算模块：正常结算流程、表单校验、取消返回、下单后清空购物车、金额计算。

## 三、测试策略
- **功能测试**：采用等价类划分、边界值分析、异常场景分析法设计用例，覆盖正常流程与异常流程。
- **界面测试**：检查页面元素排版、图片显示、文字对齐等 UI 问题。
- **性能测试**：使用 Chrome DevTools Performance 面板测量页面 LCP 指标。
- **兼容性测试**：使用 Chrome 154 浏览器进行测试。
